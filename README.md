# Clifford Anthony D'Souza — Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript. It has no build step or runtime dependencies.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. In VS Code, the workspace's **Live Server** task starts the local preview.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages** and set the source to **GitHub Actions**.
2. Push a change to `main`, or run the **Deploy portfolio to GitHub Pages** workflow from the **Actions** tab.
3. Wait for the workflow to finish, then open the Pages URL shown in the deployment job.

## Before making it public

- Verify all role titles, dates, responsibilities, performance figures, education and certification details.
- Review the profile PDF for any contact or personal details you do not want public. The PDF is linked from the site and will be publicly downloadable with it.
- The site publicly displays the supplied phone number for calls and WhatsApp, as well as an email link. The email link opens the visitor's email application; there is no backend or contact form.
- Add links to real project case studies, dashboards, demos or creative samples when available. Clearly distinguish initiatives and capability areas from completed work.
- Add your GitHub profile link when you are ready; no placeholder GitHub link is shown on the site.
- Google Fonts is requested from Google Fonts; the site falls back to local system fonts if unavailable.
